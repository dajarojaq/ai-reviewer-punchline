A Node 22 TypeScript entry for the make.fun bounty **The joke the reviewer laughs at**. It writes a single-line UTF-8 joke about working beside AI coding agents to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (default `/output`).

## Run it

```sh
node main.ts
```

Or with a custom output directory:

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
